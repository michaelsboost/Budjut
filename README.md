# 💸 Budjut – Budgeting Without the Bloat

===================

![](https://raw.githubusercontent.com/michaelsboost/Budjut/gh-pages/imgs/screenshot.jpeg)

## 🌟 Overview

Budjut is a lightweight, browser-based budgeting app built for everyday people who want simple financial control without subscriptions, ads, or invasive tracking. Designed to be fast, private, and easy to use, Budjut helps users track monthly expenses, estimate income from weekly pay, and manage budgeting data with CSV support.

### **🧠 Philosophy**

Budjut avoids unnecessary complexity, social feeds, and bloated finance tools. It focuses on clarity, speed, ownership, and privacy.

> “A budget is telling your money where to go instead of wondering where it went.” – Dave Ramsey

## 🛠️ Key Features

**💸 Expense Tracking**

* Add, edit, and delete monthly expenses
* Clean and organized expense management table
* Real-time updates and calculations

**📆 Smart Income Estimation**

* Convert weekly income into estimated monthly income
* Automatic monthly forecasting using 52-week calculation
* Helps users understand realistic monthly cash flow

**📊 Budget Health Overview**

* Displays total expenses and remaining income
* Spending percentage progress bar
* Overspending alerts when expenses exceed income

**📁 CSV Import & Export**

* Export budgeting data as CSV
* Import CSV expense sheets
* Downloadable example CSV template included

**💾 Persistent Local Storage**

* Saves all budgeting data locally
* No account creation required
* No cloud dependency or server storage

**🎨 Modern Minimal UI**

* Responsive dark-mode interface
* Glassmorphism-inspired design
* Mobile-friendly and lightweight

**🔒 Privacy Focused**

* Entirely client-side
* No tracking
* No analytics
* Your data stays on your device

## **⚡ Getting Started**

### **1️⃣ Install & Run Locally**

```sh
# Clone the repository
git clone https://github.com/michaelsboost/Budjut.git
cd Budjut

# Open index.html in a browser
```

### **2️⃣ Dependencies**

* Alpine.js (reactive functionality)
* TailwindCSS (styling)
* Vanilla JavaScript
* HTML5 LocalStorage API

### **📁 CSV Format Example**

```csv
Name,Amount
Rent,850
Electric,100
Internet,65
```
